Camera calibration

Set a camera's map x/y/yaw offset, mount yaw and horizontal field of view in the camera registration form/API. Object positions need both a current pose and known tool width.

Collect tool images

Upload varied views for each tool. Draw a box around every visible instance. Unlabeled images do not train YOLO.

Train local detector

The API builds an Ultralytics YOLO dataset from saved boxes. Use multiple backgrounds and angles; aim for at least 20–50 labeled images per class for a useful prototype.
