How it works

Cameras collect. Models interpret. People verify.

Anytime organizes short visual observations into a shared timeline. Every useful claim points back to the frame that produced it.

Observe

02 / Identify

Recognize

Object detection tracks important tools; a vision model drafts descriptions of visible actions.

03 / Remember

Connect

A central server combines camera records into individual and team timelines.

The prototype

Built for real workflows, designed to adapt.

The current project combines an edge capture agent, visual reasoning, a tool labeling workflow, and a searchable team timeline. The same structure can describe a robotics workshop or an industrial site.

EdgeRaspberry Pi camera agent and optional Limelight AprilTag observations
VisionNVIDIA Nemotron for draft descriptions; a custom YOLO training workflow for team tools
MemoryFastAPI, timestamped observations, source frames, and local SQLite storage
InterfaceIndividual and shared timelines, evidence search, and a map for location estimates
